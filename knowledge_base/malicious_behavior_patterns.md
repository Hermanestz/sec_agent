# 恶意行为模式分析指南

本文档详细说明了如何根据收集到的证据，识别和归类不同的网络安全威胁。

## 1. 子域名接管 (Subdomain Takeover)

- **核心前提:** 存在指向第三方云服务的 **CNAME** 记录 (e.g., `*.github.io`, `s3.amazonaws.com`, `*.netlify.app`, `*.herokuapp.com`).
- **网页内容:**
        - HTTP响应为 404 / 403 或服务商默认错误页（如 GitHub 的 "No such site"，AWS S3 的 "No Such Bucket"）。
        - 页面内容与主业务无关（如显示测试内容、空白页）。
- **指纹信息:** "There isn't a GitHub Pages site here", "No Such Bucket", "No such app".
- **结论:** 攻击者可以随时占据此子域名。

## 2. 钓鱼网站 (Phishing)

- **时效性:** 域名注册时间通常很短（小于90天）。这表现出“一次性”使用的特点。
- **伪装性:** 域名本身模仿知名品牌（Typosquatting），或使用免费SSL证书（如Let's Encrypt）来获取HTTPS的“安全”假象。
- **内容:** 网页内容包含“登录”、“密码”、“账户”、“验证”等关键词，或直接模仿知名网站的登录页面。

## 3. 僵尸网络C&C服务器 (Botnet C2)

- **域名结构:** DGA模型检测结果为 "dga"。
- **隐蔽性:**
        - 通常没有网站内容（HTTP服务可能关闭或返回空白/默认页）。
        - 通常**没有MX记录**，因为C2服务器不需要接收邮件。
- **灵活性:** DNS历史记录可能显示IP地址频繁变更，且TTL值通常设置得很短。

## 4. 恶意软件分发 (Malware Distribution)

- **信誉:** 在OTX、VirusTotal等威胁情报平台上有明确的恶意软件分发标记。
- **内容:** 网页内容包含诱导性下载链接、伪装成软件更新或包含已知的恶意脚本。

## 5. 垃圾邮件活动 (Spam Campaign)

- **网站目的:** 从域名和网页内容分析有邮件活动需求。
- **DNS记录:** 没有MX, SPF, DMARC记录。
- **辅助特征:** 域名注册时间短，且托管于低信誉的ASN（自治系统编号）。
